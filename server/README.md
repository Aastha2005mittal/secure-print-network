# Secure-Network-Print

## Description
A secure and anonymous document printing system. Users can upload files anonymously using QR codes linked to each print shop. Files are stored securely and auto-deleted nightly. Shopkeepers can download and print without seeing user personal information.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MySQL
- File Storage: Local/AWS S3
- Notifications: Socket.io (optional)
- Cron Jobs: node-cron
